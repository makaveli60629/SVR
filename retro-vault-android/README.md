# Retro Vault Android Test
Android WebView test package for user-supplied legally obtained ROMs/BIOS files.

## Test flow
1. Install the debug APK.
2. Open Retro Vault.
3. Tap Select Game File.
4. Pick a small ROM you are authorized to use (NES/GBA are good first tests).
5. Leave System on Auto Detect and tap Start Game.

This test build loads EmulatorJS from its stable CDN, so internet access is required.
No ROMs or proprietary BIOS files are included.

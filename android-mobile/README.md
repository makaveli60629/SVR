# SVR Poker Mobile Android wrapper

This is a test APK wrapper for the standalone /mobile product.

The APK packages the standalone mobile shell locally and routes the existing poker, tournament, account and VR links to https://svrpoker.com/.

Build:
- application id: com.svrpoker.mobile.test (debug)
- version: 0.1.0-mobile-mvp1-test
- play money only
- billing and ad adapters remain disabled until production SDK integration

GitHub Actions builds the debug APK and uploads it as an artifact.

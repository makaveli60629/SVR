# legend hall patch

- added a northwest legend hall of fame area
- three pedestals for free ghost, mutant, and mutant2
- solid rope rail perimeter so players do not walk through the display
- added display spotlights and hall accent lights
- used lower-case naming in the package for future add-ins
- kept the area ready for a future trophy display

## important limit

The uploaded glb files are far too large to include in a game zip that must stay under 25 MB for GitHub.
This drop adds the hall structure and placeholder display mounts now.
A later pass can use optimized lower-case model files when you upload them or after they are reduced.

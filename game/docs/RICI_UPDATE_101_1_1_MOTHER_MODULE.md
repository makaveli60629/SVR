# RICI / Reiki Update 101 — 1.1 Mother Module

## Build

## Purpose
This is the master reusable sponsor/partner storefront module. Reiki is the first implementation.

## Locked rules
- Game side only.
- Website/site files untouched.
- Lobby preserved.
- Approval warning must stay visible.
- Partner content must be packet-swappable.
- No official approval implied.
- Module can later be reused nationwide for multiple sponsors/partners.

## Layout
1. Glass storefront embedded into wall.
2. Red carpet entry.
3. Silver poles and red ropes.
4. Plants and neon trim.
5. Approval-safe brand wall.
6. Small recessed circular activation room.
7. Hologram carousel.
8. Portal card to private Reiki room.

## Carousel cards
- Intro video
- About
- Symbols
- Services
- Store preview
- VIP promo
- Enter room

## Controls
- Q = previous hologram card
- E = next hologram card
- Enter = activate selected card
- Mouse / ray select = card buttons

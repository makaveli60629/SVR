# Scorpion Chip Flow QA — Phase 101

## Visual checks

- Chips stay flat on felt.
- Player chip area stays outside/behind the pass line.
- Bets move inside the pass line.
- Pot pile stays visible and does not cover cards.
- Winner payout sweep is visible.
- Winner stack growth is visible.

## UX checks

- Winner banner is readable.
- Winning hand name is readable.
- Hand history is readable and not cluttered.
- Winner moment has a short pause before next hand.

## Regression checks

- Cards still deal left-to-right.
- Timer still works.
- Auto-check and auto-fold still work.
- Auto-staged call amount still works.
- Watch remains usable.
- Quest controls remain valid.
- No website or SQL files changed.

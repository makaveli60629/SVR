Data Wiring

Required private endpoints

Use a secured API for all live data. The public site should call public-safe routes; owner/admin panels should read aggregate analytics only after owner authentication.

Visitor analytics

POST /api/analytics/event records silent page views and button clicks. GET /api/admin/analytics/summary returns private counts for this panel.

Messages

POST /api/messages saves visitor questions, sponsor inquiries, and support requests to backend storage.

Admin status

GET /api/admin/status powers the Admin Online / Offline indicator. Admin controls should require authentication.

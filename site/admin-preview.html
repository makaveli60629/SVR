Use AWS for all live data. The public site should call a secured API; the admin panel should read aggregate analytics only after owner authentication.

Messages

POST /api/messages saves visitor questions, sponsor inquiries, and support requests to AWS-backed storage.

Admin status

GET /api/admin/status powers the Admin Online / Offline indicator. Admin controls should require authentication.

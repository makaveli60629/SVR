Stripe Sandbox

Sandbox Mode Only

Stripe can be wired safely, but the public website should only call your backend endpoint. The backend creates the checkout session using secret keys stored in Azure App Service settings.

Store HubCartStripe Sandbox

Frontend flow

The site sends cart items to a secure route. It never contains Stripe secret keys.

  1. Visitor builds cart.
  2. Visitor clicks sandbox checkout.
  3. Frontend calls /api/stripe/create-checkout-session.
  4. Backend creates Stripe Checkout Session in test mode.
  5. Visitor is redirected to Stripe-hosted checkout.

Settings to wire later

These go in Azure App Service settings, not the website files.

STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
STORE_CHECKOUT_ENABLED=false

Keep checkout disabled until products, taxes, fulfillment, and legal text are approved.

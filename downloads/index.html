Phone Test

  1. Open this page on Android Chrome.
  2. Tap Install Site App to test PWA install.
  3. Tap Android Safe Mode.
  4. Use LOBBY, TABLE, STORE, PGA, REIKI, and SCORPION tap buttons first.
  5. If anything goes black, tap RECOVER, then RESET.
  6. Only turn WALK ON after tap-move works.
